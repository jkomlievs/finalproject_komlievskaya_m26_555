# ValutaTrade Hub

Консольное приложение для управления виртуальным портфелем валют: регистрация пользователей, покупка/продажа валют, отслеживание курсов (фиат и криптовалюты) и просмотр портфеля.

## Возможности

- Регистрация и авторизация пользователей (`register`, `login`, `logout`)
- Покупка и продажа валют (`buy`, `sell`)
- Просмотр курса пары валют (`get-rate`)
- Просмотр портфеля пользователя (`show-portfolio`)
- Обновление курсов из внешних API — CoinGecko (крипто) и ExchangeRate-API (фиат) (`update-rates`)
- Просмотр курсов из локального кэша (`show-rates`)
- Интерактивный режим (REPL) и режим одиночных команд

## Установка и запуск

bash
uv sync
uv run python main.py

## Модель расчётов при покупке/продаже валюты

В проекте реализована **упрощённая модель** операций `buy`/`sell`:
- `buy` увеличивает баланс покупаемой валюты в портфеле пользователя.
- `sell` уменьшает баланс продаваемой валюты.
- USD-кошелёк не списывается и не пополняется — стоимость операции в USD рассчитывается и выводится как **оценочная** (на основе текущего курса), но не влияет на баланс USD.

Эта модель выбрана, поскольку задание не предоставляет механизма начисления стартового баланса USD при регистрации, а пошаговое описание команд `buy`/`sell` не требует списания/зачисления USD как обязательного шага.

## Настройка Parser Service

Для получения курсов фиатных валют через ExchangeRate-API нужен бесплатный
API-ключ (необходимо зарегистрироваться на https://www.exchangerate-api.com/).

Создать файл `.env` в корне проекта:


EXCHANGERATE_API_KEY=твой_ключ


Для получения курсов криптовалют (CoinGecko) ключ не требуется — API открытый.

Запустить обновление курсов командой:

> update-rates

Update successful. Total rates updated: 6.


## Кэширование курсов и TTL

Курсы валют хранятся локально в `data/rates.json` — это "снимок" последних
актуальных значений, полученных от CoinGecko и ExchangeRate-API.
У кэша есть срок годности (TTL), заданный в настройках: если курс устарел,
приложение предупреждает об этом и предлагает выполнить `update-rates`
для обновления данных. История всех измерений сохраняется в
`data/exchange_rates.json` для анализа динамики.
